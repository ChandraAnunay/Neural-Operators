# Neural Operators

This repository contains my implementations of **Neural Operators**, built as part of my journey into Scientific Machine Learning. Rather than relying on existing libraries, I implement the models from scratch to better understand the mathematics and the architecture behind them.

Currently, the repository includes:

```
Neural Operators/
├── DeepONets/
│   ├── 0_Theory.ipynb
│   ├── 1_Antiderivative_DeepONet.ipynb
│   └── 2_Heat_Equation_DeepONet.ipynb
│
├── FNOs/
│   ├── 0_Theory.ipynb
│   └── 1_Heat_Equation.ipynb
│
└── README.md
```

### What's inside?

- Notes on the underlying theory
- DeepONet implementations
- Fourier Neural Operator (FNO) implementations
- PDE examples
- PyTorch code with step-by-step development

I'll continue adding more neural operator architectures and applications as I explore the field.
